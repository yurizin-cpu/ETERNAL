# ETERNAL

Site estático preparado para GitHub Pages.

- Cenas automáticas: 2 segundos por cena.
- Música: botão para ativar/desativar + volume.
- Painel BG: personalização do universo/background.
- Funciona em PC e celular.

## Publicar
Em GitHub: Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
